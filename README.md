# 소금의 코스피 데일리

## 공개 주소 만들기 (GitHub Pages)

1. GitHub 계정으로 로그인하고 **Public** 저장소를 `kospi-daily` 이름으로 만듭니다. 저장소명은 변경해도 됩니다.
2. 이 압축파일 내용물을 **압축 해제한 뒤**, 내부 파일과 숨김 폴더 `.github`까지 그대로 저장소 루트에 업로드합니다. (브라우저 업로드에서 `.github`가 누락되지 않게 주의하세요.)
3. 저장소 기본 브랜치 이름이 **main**인지 확인합니다.
4. GitHub 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
5. **Actions** 탭에서 `Daily KOSPI screen and deploy`를 선택하고 **Run workflow**를 한 번 실행합니다.
6. 초기 배포 후 주소: `https://본인-GitHub-아이디.github.io/kospi-daily/` (저장소명에 따라 달라짐).

## 자동 작동

- 한국시간 월~금 오전 8:30 전후 자동 스캔하여 페이지를 재배포합니다. GitHub의 예약 실행은 지연/누락될 수 있습니다.
- 전일 종가 기준 전통적 이동평균·거래량·ATR 규칙을 적용합니다. 실제 장중 실시간 신호가 아닙니다.
- **당일 거래에 사용할 경우 개장 직전 데이터와 기업 공시를 별도로 검증해야 합니다.**
- 휴일, 가격 데이터 지연, 필터 부적합 시 '관망'. 일부 휴일은 인식하지 못할 수 있으므로 거래일 여부를 별도로 확인하세요.
- 종목풀은 generate.py의 `STOCKS`에서 변경할 수 있습니다. 코스피 종목만 포함했습니다.
- 저장소를 공개하면 사이트와 알고리즘도 공개됩니다.
- 주식 자동 주문/수익률 추적/실시간 주가/기업 공시 감시 기능은 포함되지 않습니다.

## 유의

이는 일별 기술적 스크리너의 **시작용 템플릿**이며, 백테스트로 검증된 전략이 아닙니다. 목표수익가가 과거 변동성을 바탕으로 계산됐다는 이유만으로 도달 가능성이 보장되는 것은 아닙니다. 손실과 주문 미체결이 발생할 수 있습니다. 무료 데이터 소스는 간헐적으로 접근 제한 또는 오류가 발생할 수 있습니다.
